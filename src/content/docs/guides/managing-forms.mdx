A form holds everything FormWire needs to handle one form on your site, including its submission endpoint, its validation schema, its notification settings, and its integrations.

## Create a form

Click **New Form** in the dashboard and enter a **name** (1 to 90 characters). You can also add a **description**. FormWire generates the form's secret and submission endpoint when you create it.

You can add **tags** to a form to group related forms and filter your form list.

## Settings

You can change these settings at any time.

| Setting | What it does |
| --- | --- |
| **Name** | The label you see in the dashboard (1 to 90 characters). |
| **Description** | Optional notes for your own reference. |
| **Enabled** | When this is off, the endpoint rejects every submission. |
| **Email notifications** | Sends an email for each submission to this form. See [Email Notifications](/guides/email-notifications). |
| **Redirect URL** | Where visitors go after a successful HTML form post. It must be a valid URL. |
| **Success message** | The message returned in the JSON response on success (up to 500 characters). |
| **Submission limit** | The maximum number of submissions the form accepts in a time window. See [Submission limits](#submission-limits). |
| **Validation schema** | Optional rules for field types and required fields. See [Schema Validation](/guides/schema-validation). |

## Redirects and JSON responses

The response to a successful submission depends on how it was sent:

- An **HTML form post** (`application/x-www-form-urlencoded`) to a form that has a **redirect URL** redirects the visitor to that URL.
- Every other submission gets a JSON response that contains the success message, the submission ID, and the time it was received. This includes JSON posts and HTML form posts when no redirect URL is set.

The [React guide](/frameworks/react#handle-the-response) shows the JSON response and the error codes.

## Submission limits

You can limit how many submissions a form accepts. Set a **maximum count** and choose a **window**:

| Window | When the count resets |
| --- | --- |
| `daily` | At the start of each day |
| `weekly` | At the start of each week |
| `monthly` | At the start of each month |
| `yearly` | At the start of each year |
| `all_time` | Never. The limit applies to the form's whole lifetime. |

When the form reaches its limit, it rejects further submissions until the window resets. Leave the limit empty to accept unlimited submissions.

This limit is separate from your plan's monthly quota, which counts submissions across all your forms. See [Plans & Limits](/billing/plans-and-limits).

## Regenerate the form secret

If your form secret is being abused, click **Regenerate Secret** in the form's settings. FormWire creates a new secret, and the old endpoint stops working immediately.

:::caution
Your form can't receive submissions until you update your site with the new endpoint.
:::

## Delete a form

:::danger
Deleting a form also deletes all of its submissions, and you can't undo it. [Export](/guides/exporting-data) the submissions you want to keep first.
:::
