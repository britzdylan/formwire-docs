## Get started

<CardGrid stagger>
	<Card title="Receive your first submission" icon="rocket">
		Create a form, set your HTML form's `action` to the endpoint, and submit.
		The [quickstart](/getting-started/quickstart/) takes about five minutes.
	</Card>
	<Card title="Use your own stack" icon="seti:react">
		There are guides for [HTML](/frameworks/html/), [React](/frameworks/react/),
		[Vue](/frameworks/vue/), [Next.js](/frameworks/nextjs/), and
		[Framer](/frameworks/framer/). Anything that can send a `POST` request works.
	</Card>
	<Card title="Filter spam" icon="approve-check">
		Every submission gets a spam score from a honeypot field, a timing check,
		and content analysis. See [spam protection](/guides/spam-protection/).
	</Card>
	<Card title="Validate fields" icon="document">
		Add a [schema](/guides/schema-validation/) to require fields and check
		their types. Submissions that fail are flagged for review and still stored.
	</Card>
	<Card title="Forward submissions" icon="puzzle">
		Send each submission to your own backend, Slack, or Zapier with a
		[webhook integration](/integrations/).
	</Card>
	<Card title="See where submissions come from" icon="magnifier">
		Each submission records its referrer, location, device, and UTM
		parameters. [How it works](/getting-started/how-it-works/) lists
		everything that is captured.
	</Card>
</CardGrid>
