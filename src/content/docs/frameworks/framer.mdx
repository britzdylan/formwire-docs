You can send a Framer form's submissions to FormWire in two ways. Framer's built-in form component is the simplest. A Code Component gives you control over the request.

## Use Framer's form component

In Framer, select your form and set it to send submissions to a **webhook**. Enter your FormWire endpoint as the webhook URL:

```txt
https://api.formwire.app/v1/submit/YOUR_FORM_SECRET
```

Each Framer field's name becomes a field in the stored submission.

Framer sends these submissions from its own servers, not from the visitor's browser. This has three effects:

- The IP address, location, and device stored with each submission describe Framer's servers.
- What the visitor sees after submitting is controlled in Framer. FormWire's redirect URL doesn't apply.
- The timing check doesn't work, as explained under [Timing check](#timing-check).

## Use a Code Component

If you want the browser to send the submission, build the form as a Framer Code Component and call the endpoint with `fetch`. The code is the same as in the [React guide](/frameworks/react). FormWire then records each visitor's own location and device, and every spam check works.

## Honeypot

Add a field named `_fw_hp` to your form and hide it from visitors. A submission with a value in that field is marked as spam. See [Spam Protection](/guides/spam-protection#honeypot-field).

## Timing check

:::caution[Framer's form component]
The timing check doesn't work with Framer's form component. The component has no way to record when the page loaded and send that time as the `_fw_loaded` field.
:::

The timing check works in a Code Component. Record the time when the form mounts, and send it as `_fw_loaded`:

```tsx
// Record when the form mounts.
const loadedAt = useRef(Date.now())

async function handleSubmit(values) {
  await fetch("https://api.formwire.app/v1/submit/YOUR_FORM_SECRET", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ ...values, _fw_loaded: loadedAt.current }),
  })
}
```

[Spam Protection](/guides/spam-protection#timing-check) explains how the timing check affects the spam score.
