A form without a schema accepts any fields you send. To require certain fields or check their types, add a **validation schema** to the form.

Validation never rejects a submission. A submission that fails validation is still stored. FormWire gives it the `pending_review` status and records each error so that you can see what was wrong.

## Define a schema

You add field rules in the form's **Validation** tab. Each rule names a field, sets its **type**, and says whether it is **required**. A schema looks like this:

```json
{
  "fields": {
    "email":   { "type": "email",  "required": true },
    "name":    { "type": "string", "required": true },
    "age":     { "type": "number", "required": false },
    "website": { "type": "url",    "required": false }
  }
}
```

A submission can leave out a field that is not required. If the field is present, it must still match its type.

## Field types

| Type | What it accepts |
| --- | --- |
| `string` | Text that is not empty |
| `number` | A number |
| `boolean` | A boolean |
| `accepted` | A value that means "yes", such as a checked checkbox |
| `date` | A valid date |
| `email` | An email address. FormWire normalizes it before storing. |
| `alpha` | Letters only |
| `alphaNumeric` | Letters and numbers only |
| `confirmed` | A value that matches a second field named `<field>_confirmation` |
| `ipAddress` | An IP address |
| `uuid` | A UUID |
| `creditCard` | A credit card number |
| `hexCode` | A hex color code |
| `iban` | An IBAN |
| `coordinates` | Geographic coordinates |
| `mobileNumber` | A mobile phone number, checked strictly |
| `url` | A URL that starts with `http://` or `https://` |

## Validation results

Each submission gets one of these validation statuses:

| Status | Meaning |
| --- | --- |
| `not_validated` | The form has no schema. |
| `validated` | Every field in the schema passed, and the submission had no other fields. |
| `partially_validated` | Every field in the schema passed, and the submission also had fields that are not in the schema. |
| `failed` | At least one field failed. |

## Fields outside the schema

FormWire checks the fields in your schema and accepts any others. Extra fields are stored with the submission and listed as **unknown fields**, and the validation status becomes `partially_validated`. This means you can add a field to your site's form before you add it to the schema.
