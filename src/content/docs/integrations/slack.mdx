## Use a webhook today

You can already post submissions to Slack using an incoming webhook:

<Steps>

1. In Slack, create an **Incoming Webhook** and copy its URL.
2. In FormWire, create a [webhook integration](/integrations/webhooks) pointing at that URL.
3. Attach it to the forms you want to notify a channel.

</Steps>

New submissions will be delivered to Slack as JSON. The dedicated integration will add nicely formatted messages and channel selection.
