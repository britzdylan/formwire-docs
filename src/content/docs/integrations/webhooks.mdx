A webhook integration sends each new submission to a URL you choose, as a JSON `POST` request. Use it to connect FormWire to your own backend or to any service that accepts incoming webhooks.

## Create a webhook

Go to **Integrations** in your account settings, create a webhook integration, and fill in:

- **Name.** A label for the integration.
- **URL.** The endpoint FormWire sends requests to. It must start with `http://` or `https://`.
- **Custom headers** (optional). Name and value pairs that FormWire adds to every request. Use them to authenticate the request, for example with an `Authorization` or `X-Api-Key` header.

Then open each form that should use the webhook and link it in the form's **Integrations** tab.

## Request body

FormWire sends a `POST` request with `Content-Type: application/json` and this body:

```json
{
  "submissionId": "b1f2…",
  "formId": "a9c8…",
  "data": {
    "name": "Ada Lovelace",
    "email": "ada@example.com",
    "message": "Hello!"
  },
  "submittedAt": "2026-05-29T10:00:00.000Z"
}
```

`data` contains the submitted fields. The reserved `_fw_hp` and `_fw_loaded` fields are removed before delivery.

## Authenticate requests

Add a custom header that only you and FormWire know. For example, with a header named `X-Api-Key` and the value `your-secret-value`, FormWire sends:

```http
POST /your/endpoint HTTP/1.1
Content-Type: application/json
X-Api-Key: your-secret-value
```

Check the header in your endpoint and reject requests that don't have the right value.

## Which submissions are sent

FormWire sends submissions that have the `new` status. Submissions flagged as `spam` or `pending_review` are not sent, and they show a failed delivery. To send one, change its status to `new` and click **Retry failed** on the submission.

## Success and failure

- Respond with a **2xx** status code to confirm you received the submission.
- Any other status code counts as a failure. The same applies if FormWire can't reach your URL.
- When a delivery fails, FormWire records the error on the submission and notifies you by email and in the dashboard.
- FormWire doesn't retry automatically. Open the submission and click **Retry failed** to send it again. See [Submissions](/guides/submissions#retry-a-failed-integration).

## Connect other tools

Any service that accepts a JSON `POST` request works with a webhook integration. The [Zapier](/integrations/zapier) and [Slack](/integrations/slack) pages show two examples.
