In Next.js, you can submit to FormWire from the browser in a Client Component or from your server in a Server Action.

Submit from a Client Component unless you have a reason not to. FormWire then sees each visitor's own request, so the location, device, and referrer it records are theirs.

<Tabs>
<TabItem label="Client Component" icon="seti:react">

```jsx title="app/contact/contact-form.js"
"use client";
import { useState } from "react";

const ENDPOINT = "https://api.formwire.app/v1/submit/YOUR_FORM_SECRET";

export function ContactForm() {
  const [status, setStatus] = useState("idle");

  async function handleSubmit(event) {
    event.preventDefault();
    setStatus("submitting");
    const payload = Object.fromEntries(new FormData(event.target).entries());
    const res = await fetch(ENDPOINT, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(payload),
    });
    setStatus(res.ok ? "success" : "error");
  }

  if (status === "success") return <p>Thanks for your message!</p>;

  return (
    <form onSubmit={handleSubmit}>
      <input name="email" type="email" required />
      <textarea name="message" />
      {/* Honeypot field, hidden from people */}
      <input
        name="_fw_hp"
        tabIndex={-1}
        autoComplete="off"
        aria-hidden="true"
        style={{ position: "absolute", left: "-9999px" }}
      />
      <button disabled={status === "submitting"}>Send</button>
      {status === "error" && <p>Something went wrong. Please try again.</p>}
    </form>
  );
}
```

</TabItem>
<TabItem label="Server Action" icon="forward-slash">

A Server Action sends the submission from your server, so the form secret never reaches the browser:

```jsx title="app/contact/actions.js"
"use server";

export async function submitContact(formData) {
  const payload = Object.fromEntries(formData.entries());
  const res = await fetch(
    `https://api.formwire.app/v1/submit/${process.env.FORMWIRE_SECRET}`,
    {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(payload),
    }
  );
  if (!res.ok) throw new Error("Submission failed");
}
```

```jsx title="app/contact/page.js"
import { submitContact } from "./actions";

export default function ContactPage() {
  return (
    <form action={submitContact}>
      <input name="email" type="email" required />
      <textarea name="message" />
      <button>Send</button>
    </form>
  );
}
```

Store the secret in an environment variable such as `FORMWIRE_SECRET`.

:::caution[What changes when you submit from your server]
FormWire sees your server's request, not the visitor's. This has two effects:

- The IP address, location, device, and referrer stored with each submission describe your server.
- The limit of 30 requests per minute per IP address applies to your server as a whole, across all of your visitors.
:::

</TabItem>
</Tabs>

The response is the same in both cases. The [React guide](/frameworks/react#handle-the-response) shows it and lists the error codes.
