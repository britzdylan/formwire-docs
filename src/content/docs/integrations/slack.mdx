## Send submissions to Slack now

A FormWire webhook can't post to a Slack incoming webhook URL directly. Slack expects a message in its own format, and FormWire sends the [submission as JSON](/integrations/webhooks#request-body). You need a step in between that turns the submission into a Slack message.

The quickest way is Zapier:

<Steps>

1. In Zapier, create a Zap with the **Webhooks by Zapier** app and its **Catch Hook** trigger. Copy the webhook URL.
2. In FormWire, create a [webhook integration](/integrations/webhooks) with that URL and link it to your forms.
3. Submit your form once so that Zapier receives a sample request.
4. Add a Slack action to the Zap that sends a channel message, and build the message from the fields in the `data` object.

</Steps>

If you'd rather not use Zapier, point the webhook at a small function of your own that formats the message and posts it to a Slack incoming webhook URL.
