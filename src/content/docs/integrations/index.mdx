## How integrations work

- You create an integration once, then attach it to one or more forms.
- When a submission is received, FormWire dispatches it to each active integration attached to that form.
- An integration can be toggled **active/inactive** without deleting it.
- If a delivery fails, you can **retry** it from the submission — see [Submissions](/guides/submissions).

## Data forwarded

When you enable an integration you instruct FormWire to send submission data to a destination outside our control, governed by that provider's own terms. You're responsible for the destinations you choose. See the [Terms of Service](/terms) and [Privacy Policy](/privacy).
