## Send submissions to GitHub with a webhook

The GitHub API needs its own request format, so FormWire can't post to it directly. Point a [webhook integration](/integrations/webhooks) at a service that you control, such as a serverless function or a Zapier Zap, and have that service call the GitHub API. For example, it could open an issue for each submission.
