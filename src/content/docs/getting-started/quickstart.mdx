This guide takes you from a new account to your first stored submission. It takes about five minutes.

<Steps>

1. ### Create an account

   <LinkButton
     href="https://portal.formwire.app/auth/signup"
     variant="primary"
     icon="external"
     iconPlacement="start"
   >
     Sign up for a free FormWire account
   </LinkButton>

2. ### Create a form

   In the dashboard, click **New Form** and give it a name. FormWire generates a **form secret** and a submission endpoint that contains it:

   ```txt
   https://api.formwire.app/v1/submit/YOUR_FORM_SECRET
   ```

   You can copy the endpoint from the form's **Settings** tab.

3. ### Point your form at the endpoint

   Set the `action` of any HTML form to your endpoint:

   ```html
   <form action="https://api.formwire.app/v1/submit/YOUR_FORM_SECRET" method="POST">
     <input type="text" name="name" placeholder="Your name" required />
     <input type="email" name="email" placeholder="Your email" required />
     <textarea name="message" placeholder="Your message"></textarea>
     <button type="submit">Send</button>
   </form>
   ```

   Each `name` attribute becomes a field in the stored submission.

   The form's **Setup** tab also generates this code for HTML and the common frameworks, with your endpoint already filled in.

4. ### Submit the form

   Open the page in a browser, fill in the form, and submit it. The submission appears in the form's **Submissions** tab, along with the metadata FormWire captured.

</Steps>

:::tip[Send visitors to a thank-you page]
A plain HTML form post returns a JSON response by default. To send visitors to your own page instead, set a **redirect URL** in the form's settings. See [Managing Forms](/guides/managing-forms).
:::
