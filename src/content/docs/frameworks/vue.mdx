In Vue, you send the form's values to your submission endpoint as JSON and update your component from the response.

## Basic example

```vue
<script setup>
import { reactive, ref } from "vue";

const ENDPOINT = "https://api.formwire.app/v1/submit/YOUR_FORM_SECRET";

const form = reactive({ name: "", email: "", message: "", _fw_hp: "" });
const status = ref("idle");

async function submit() {
  status.value = "submitting";
  const res = await fetch(ENDPOINT, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(form),
  });
  status.value = res.ok ? "success" : "error";
}
</script>

<template>
  <p v-if="status === 'success'">Thanks for your message!</p>
  <form v-else @submit.prevent="submit">
    <input v-model="form.name" placeholder="Your name" required />
    <input v-model="form.email" type="email" placeholder="Your email" required />
    <textarea v-model="form.message" placeholder="Your message" />
    <!-- Honeypot field, hidden from people -->
    <input
      v-model="form._fw_hp"
      tabindex="-1"
      autocomplete="off"
      aria-hidden="true"
      style="position: absolute; left: -9999px"
    />
    <button :disabled="status === 'submitting'">Send</button>
    <p v-if="status === 'error'">Something went wrong. Please try again.</p>
  </form>
</template>
```

## Handle the response

A successful submission returns status `201` and a JSON body with `success`, `message`, and a `data` object that contains `submissionId`, `receivedAt`, and `redirectUrl`.

A rejected submission returns an error status and a body with `success: false` and an error code in `message`. The code is not text for your visitors, so check `res.ok` and show your own message.

The [React guide](/frameworks/react#handle-the-response) shows both bodies and lists the error codes. They are the same for every framework.
