FormWire works with any React form. Post your form data as JSON (or `FormData`) to your submission endpoint and handle the response in your component.

## Basic example

```jsx title="ContactForm.jsx"
import { useState } from "react";

const ENDPOINT = "https://api.formwire.app/v1/submit/YOUR_FORM_SECRET";

export function ContactForm() {
  const [status, setStatus] = useState("idle");

  async function handleSubmit(event) {
    event.preventDefault();
    setStatus("submitting");

    const formData = new FormData(event.target);
    const payload = Object.fromEntries(formData.entries());

    const res = await fetch(ENDPOINT, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(payload),
    });

    setStatus(res.ok ? "success" : "error");
  }

  if (status === "success") return <p>Thanks for your message!</p>;

  return (
    <form onSubmit={handleSubmit}>
      <input name="name" placeholder="Your name" required />
      <input name="email" type="email" placeholder="Your email" required />
      <textarea name="message" placeholder="Your message" />
      {/* Honeypot — hidden from real users */}
      <input
        name="_fw_hp"
        tabIndex={-1}
        autoComplete="off"
        style={{ position: "absolute", left: "-9999px" }}
      />
      <button disabled={status === "submitting"}>Send</button>
      {status === "error" && <p>Something went wrong. Please try again.</p>}
    </form>
  );
}
```

## Handling the response

A JSON submission returns:

```json
{
  "success": true,
  "message": "Thanks for your submission!",
  "data": {
    "submissionId": "…",
    "receivedAt": "2026-05-29T10:00:00.000Z",
    "redirectUrl": null
  }
}
```

On failure, the response is non-2xx with `success: false` and a `message`. Check `res.ok` and surface the message to the user. Common cases: the form is disabled, a submission limit was hit, or the payload was empty or too large (50&nbsp;KB max).
