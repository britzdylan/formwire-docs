You can download a form's submissions as a CSV file, or send each new submission to your own system as it arrives.

## Export a CSV file

Open a form, go to its **Submissions** tab, and click **Export CSV**.

The file contains the submissions currently shown in the list. To export only some of them, search the list first.

Each row is one submission. The columns are:

- **Received**, **Status**, **Spam**, **Country**, and **Valid**
- One column for each field that appears in the exported submissions

The file is UTF-8 and opens in Excel, Google Sheets, and Numbers.

:::note
JSON export is planned. Until then, a webhook gives you each submission as JSON.
:::

## Keep a live copy with a webhook

A [webhook integration](/integrations/webhooks) sends every new submission as JSON to a URL you choose, such as a serverless function or a database endpoint. Use this when you want your own copy of the data without exporting by hand.

## Export before you delete

Deleting a form deletes its submissions, and deleting your account deletes all of your data. You can't undo either one, so export what you want to keep first.
