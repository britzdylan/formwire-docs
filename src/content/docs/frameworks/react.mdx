In React, you send the form's values to your submission endpoint as JSON and update your component from the response.

## Basic example

```jsx title="ContactForm.jsx"
import { useState } from "react";

const ENDPOINT = "https://api.formwire.app/v1/submit/YOUR_FORM_SECRET";

export function ContactForm() {
  const [status, setStatus] = useState("idle");

  async function handleSubmit(event) {
    event.preventDefault();
    setStatus("submitting");

    const formData = new FormData(event.target);
    const payload = Object.fromEntries(formData.entries());

    const res = await fetch(ENDPOINT, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(payload),
    });

    setStatus(res.ok ? "success" : "error");
  }

  if (status === "success") return <p>Thanks for your message!</p>;

  return (
    <form onSubmit={handleSubmit}>
      <input name="name" placeholder="Your name" required />
      <input name="email" type="email" placeholder="Your email" required />
      <textarea name="message" placeholder="Your message" />
      {/* Honeypot field, hidden from people */}
      <input
        name="_fw_hp"
        tabIndex={-1}
        autoComplete="off"
        aria-hidden="true"
        style={{ position: "absolute", left: "-9999px" }}
      />
      <button disabled={status === "submitting"}>Send</button>
      {status === "error" && <p>Something went wrong. Please try again.</p>}
    </form>
  );
}
```

## Handle the response

A successful submission returns status `201` and this body:

```json
{
  "success": true,
  "message": "Thanks for your submission!",
  "data": {
    "submissionId": "…",
    "receivedAt": "2026-05-29T10:00:00.000Z",
    "redirectUrl": null
  }
}
```

`message` is the form's **success message**. If the form doesn't have one, it is the code `M_SUBMISSION_CREATED`. `redirectUrl` is the form's redirect URL, which you can use to navigate after a JSON submission.

A rejected submission returns an error status and a body like this:

```json
{
  "success": false,
  "message": "E_FORM_DISABLED",
  "status": 403
}
```

`message` is an error code, not text for your visitors. Check `res.ok` and show your own message.

| Status | Code | Cause |
| --- | --- | --- |
| 400 | `E_EMPTY_SUBMISSION` | The request had no fields. |
| 400 | `E_PAYLOAD_TOO_LARGE` | The request was larger than 50&nbsp;KB. |
| 403 | `E_FORM_DISABLED` | The form is disabled. |
| 404 | `E_FORM_SECRET_INVALID` | No form has this secret. |
| 429 | `E_SUBMISSION_LIMIT_REACHED` | The form reached its own submission limit. |
| 429 | `E_PLAN_SUBMISSION_LIMIT_REACHED` | Your account reached its plan's monthly quota. |
| 429 | | The same IP address sent more than 30 requests to this form in a minute. |
